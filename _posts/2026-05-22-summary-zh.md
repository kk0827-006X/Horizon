## [Python 3.15 被忽视的特性](https://blog.changs.co.uk/python-315-features-that-didnt-make-the-headlines.html) ⭐️ 8.0/10

Python 3.15 通过 PEP 690 引入了惰性导入，在 threading 模块中添加了迭代器同步原语，并改进了 collections.Counter 的集合操作（包括对称差）。 这些特性提高了 Python 的性能（惰性导入减少启动时间）、并发安全性（迭代器同步）和 API 完备性（Counter 对称差），解决了开发者的长期痛点。 惰性导入可以通过 -L 标志或 importlib.set_lazy_imports() 全局启用。迭代器同步提供了一个上下文管理器，可以安全地迭代共享数据。Counter 现在支持 XOR 运算符 (^) 进行对称差，补充了 &、|、- 操作。

hackernews · rbanffy · May 21, 11:10 · [社区讨论](https://news.ycombinator.com/item?id=48220696)

**背景**: 在 Python 中，导入模块通常会立即加载并执行，这可能会减慢启动速度。惰性导入将这项工作推迟到实际使用模块时才进行。迭代器同步是必要的，因为 Python 迭代器默认不是线程安全的；新的原语有助于防止竞态条件。Counter 是用于计数的 dict 子类，集合操作如并集、交集和差集在 Python 3.10 中添加，对称差是 3.15 的新增功能。
