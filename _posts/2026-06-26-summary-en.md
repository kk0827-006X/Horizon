## [First complete reading of an entire Herculaneum scroll](https://scrollprize.org/firstscroll) ⭐️ 10.0/10

For the first time, an entire Herculaneum scroll has been read using AI and digital unwrapping technology. The Vesuvius Challenge team successfully deciphered the ancient text preserved by the eruption of Mount Vesuvius in 79 AD. This breakthrough demonstrates that AI and advanced imaging can unlock vast quantities of ancient texts from carbonized scrolls, potentially transforming our understanding of classical philosophy, literature, and history. It opens the door to reading hundreds more scrolls from the Herculaneum library, and possibly entire unexcavated libraries. The scroll was virtually unwrapped using a combination of X-ray computed tomography and machine learning models trained on visible ink. The preprint and code have been released openly, allowing researchers worldwide to explore the data and verify results.

hackernews · verditelabs · Jun 25, 15:48 · [Discussion](https://news.ycombinator.com/item?id=48675179)

**Background**: The Herculaneum scrolls were carbonized by the catastrophic eruption of Mount Vesuvius in 79 AD, preserving them as fragile lumps of charcoal. Traditional attempts to unroll them physically caused damage. In the 2000s, a 'virtual unwrapping' technique was developed, using CT scans to create 3D models and computational flattening. The Vesuvius Challenge, launched in 2023, applied modern AI and computer vision to read the hidden texts, culminating in the first full scroll being read in 2025.

## [Age verification laws risk creating a privacy-invasive 'papers, please' internet](https://expression.fire.org/p/the-papers-please-era-of-the-internet) ⭐️ 8.0/10

A new article argues that mandatory age verification laws are pushing the internet toward a 'papers, please' model that threatens user privacy, with commenters debating technological solutions like anonymous credentials and zero-knowledge proofs. This matters because widespread age verification mandates could fundamentally alter the privacy landscape of the internet, forcing users to surrender identity documents to access routine services, and creating systemic surveillance risks. The article specifically notes that existing mechanisms like photo ID uploads create risks of data breaches and misuse, while commenters highlight that zero-knowledge proofs (ZKPs) could theoretically allow age verification without revealing personal data, though practical implementation remains challenging.

hackernews · bilsbie · Jun 25, 21:44 · [Discussion](https://news.ycombinator.com/item?id=48679608)

**Background**: Age verification laws require websites to confirm users are above a certain age before granting access to age-restricted content. Current methods often involve scanning government IDs or using biometric estimates, which collect sensitive personal data. Zero-knowledge proofs are a cryptographic technique that lets a verifier confirm a claim (e.g., 'over 18') without learning the underlying data, but as EFF notes, ZKPs alone are not a complete digital ID solution and require trusted issuers.

## [German ruling: AI agents are deployer's responsibility](https://simonwillison.net/2026/Jun/25/ai-and-liability/#atom-everything) ⭐️ 8.0/10

A German court ruled Google liable for false information in AI Overviews, treating the AI-generated summaries as Google's own statements. Bruce Schneier argues this sets a precedent that AI agents should be legally considered agents of the deploying organization. This ruling could reshape liability frameworks for AI deployment, preventing companies from avoiding responsibility by blaming faulty AI. It establishes a strong incentive for organizations to ensure their AI systems are accurate and reliable before deployment. The German court emphasized that only Google has control over the AI and algorithms used in Overviews, so Google must be accountable for the results. The ruling applies specifically to errors that harm reputation or business.

rss · Simon Willison · Jun 25, 22:28

**Background**: AI agents are systems that perform tasks autonomously, often generating content or making decisions. Traditionally, companies might claim that AI errors are not their fault because the AI operates independently. This ruling challenges that notion by holding the deployer responsible for the agent's outputs, similar to how a company would be liable for mistakes made by human employees.

## [Browser Compat Data Converted to SQLite Database](https://simonwillison.net/2026/Jun/24/browser-compat-db/#atom-everything) ⭐️ 7.0/10

Simon Willison created a downloadable SQLite database from Mozilla's comprehensive browser-compat-data repository, using AI-generated scripts from Claude Code (Opus 4.8) and Codex Desktop (GPT-5.5). The ~66MB database is hosted on GitHub with open CORS headers, enabling direct querying via Datasette Lite. This tool makes browser compatibility data more accessible to developers, especially for AI-assisted coding and static site integrations. By packaging the data in SQLite with open CORS, it simplifies offline querying and enables new workflows for web development tooling. The database is built using sqlite-utils and a GitHub Actions workflow pushes it to an orphan branch to ensure CORS-friendly hosting. Users can download the database directly or explore it interactively via Datasette Lite without any server setup.

rss · Simon Willison · Jun 24, 23:59

**Background**: Mozilla maintains the browser-compat-data repository on GitHub, providing detailed browser support information for web features. SQLite is a lightweight, serverless database engine. CORS (Cross-Origin Resource Sharing) headers allow web pages to fetch resources from different origins, which is essential for client-side tools like Datasette Lite. The MDN MCP server, released in June 2026, inspired this project by demonstrating a new way to access browser compatibility data through AI agents.

## [OpenKnowledge: open-source AI-first alternative to Obsidian/Notion](https://github.com/inkeep/open-knowledge) ⭐️ 6.0/10

OpenKnowledge launched as a free, open-source WYSIWYG markdown editor with direct AI agent integrations including Claude and Codex, available as a macOS app or web UI+CLI. It combines a true WYSIWYG editing experience with built-in AI integration in an open-source package, potentially reducing reliance on proprietary tools like Obsidian and Notion for knowledge management. The tool uses Tiptap/ProseMirror for the editor, a CRDT for real-time collaboration, and supports integrations with Claude, Codex, and Cursor desktop apps. It is currently macOS-only and lacks support for local LLMs.

hackernews · engomez · Jun 25, 16:04 · [Discussion](https://news.ycombinator.com/item?id=48675435)

**Background**: WYSIWYG markdown editors allow users to see formatted text as they write, while traditional editors show raw markdown. Obsidian and Notion are popular knowledge management apps that use markdown but have limited AI integration. The Model Context Protocol (MCP) is an open standard for connecting AI systems to external tools and data. Retrieval-Augmented Generation (RAG) enhances LLM responses by retrieving relevant information from external sources.

## [OS9Map Lets Mac OS 9 Connect to Modern Social Networks](https://yllan.org/software/OS9Map/) ⭐️ 6.0/10

OS9Map is a new software tool that enables Mac OS 9 systems to directly connect to modern web services such as Bluesky and Mastodon, eliminating the need for an intermediary proxy server. This project extends the life of vintage Mac hardware by bridging a 20-year-old operating system with contemporary decentralized social networks, appealing to retrocomputing enthusiasts and preserving digital history. OS9Map implements support for both the AT Protocol (used by Bluesky) and ActivityPub (used by Mastodon) natively on Mac OS 9, requiring only 16 MB RAM minimum and 32 MB recommended.

hackernews · LaSombra · Jun 25, 15:01 · [Discussion](https://news.ycombinator.com/item?id=48674484)

**Background**: Mac OS 9, released in 1999, lacked built-in support for modern secure networking protocols, typically requiring a proxy to connect to today's web services. The AT Protocol and ActivityPub are open standards that power decentralized social networks, allowing different servers and clients to interoperate.
