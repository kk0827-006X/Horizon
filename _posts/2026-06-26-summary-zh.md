## [年龄验证法可能催生侵犯隐私的‘出示证件’互联网](https://expression.fire.org/p/the-papers-please-era-of-the-internet) ⭐️ 8.0/10

## [德国裁定：AI 代理应由部署方负责](https://simonwillison.net/2026/Jun/25/ai-and-liability/#atom-everything) ⭐️ 8.0/10

德国一家法院裁定谷歌对其 AI 概览中的错误信息负责，将 AI 生成的摘要视为谷歌自己的陈述。布鲁斯·施奈尔认为，这开创了一个先例，即 AI 代理在法律上应被视为部署机构的代理。 该裁决可能重塑 AI 部署的责任框架，防止企业将错误归咎于 AI 而逃避责任。它建立了强有力的激励机制，促使组织在部署前确保其 AI 系统准确可靠。 德国法院强调，只有谷歌对概览中使用的 AI 和算法具有控制权，因此谷歌必须对结果负责。该裁决特别适用于损害声誉或商业的错误。

rss · Simon Willison · Jun 25, 22:28

**背景**: AI 代理是自主执行任务的系统，通常生成内容或做出决策。传统上，公司可能会声称 AI 错误不是他们的错，因为 AI 独立运作。这项裁决挑战了这一观念，让部署方对代理的输出负责，类似于公司对员工错误的责任。

## [浏览器兼容数据转换为 SQLite 数据库](https://simonwillison.net/2026/Jun/24/browser-compat-db/#atom-everything) ⭐️ 7.0/10

Simon Willison 使用 Claude Code (Opus 4.8) 和 Codex Desktop (GPT-5.5) 生成的 AI 脚本，将 Mozilla 的 browser-compat-data 仓库转换成了一个可下载的 SQLite 数据库。这个约 66MB 的数据库托管在 GitHub 上并带有开放的 CORS 头，支持通过 Datasette Lite 直接查询。 该工具使浏览器兼容性数据对开发者更易获取，尤其有利于 AI 辅助编码和静态网站集成。通过将数据打包成支持开放 CORS 的 SQLite 格式，它简化了离线查询，并为 Web 开发工具带来了新的工作流程。 该数据库通过 sqlite-utils 构建，并由 GitHub Actions 工作流推送到一个孤立分支以确保 CORS 友好的托管。用户可以直接下载数据库，或通过 Datasette Lite 交互式浏览，无需部署服务器。

rss · Simon Willison · Jun 24, 23:59

**背景**: Mozilla 在 GitHub 上维护了 browser-compat-data 仓库，提供 Web 功能的详细浏览器支持信息。SQLite 是一种轻量级、无需服务器的数据库引擎。CORS（跨源资源共享）头允许网页从不同源获取资源，这对 Datasette Lite 等客户端工具至关重要。2026 年 6 月发布的 MDN MCP 服务器启发了这个项目，它展示了通过 AI 代理访问浏览器兼容性数据的新方式。

## [OpenKnowledge：开源 AI 优先的 Obsidian/Notion 替代品](https://github.com/inkeep/open-knowledge) ⭐️ 6.0/10

OpenKnowledge 作为一款免费、开源的所见即所得 Markdown 编辑器发布，直接集成了 Claude 和 Codex 等 AI 代理，支持 macOS 应用或 Web 界面+CLI。 它将真正的所见即所得编辑体验与内置 AI 集成结合在一个开源包中，有可能减少对 Obsidian 和 Notion 等专有知识管理工具的依赖。 该工具使用 Tiptap/ProseMirror 作为编辑器，CRDT 实现实时协作，并支持与 Claude、Codex 和 Cursor 桌面应用集成。目前仅支持 macOS，且缺乏对本地 LLM 的支持。

**背景**: 所见即所得 Markdown 编辑器允许用户在写作时看到格式化文本，而传统编辑器显示原始 Markdown。Obsidian 和 Notion 是使用 Markdown 的热门知识管理应用，但 AI 集成有限。模型上下文协议（MCP）是一个连接 AI 系统与外部工具和数据的开放标准。检索增强生成（RAG）通过从外部来源检索相关信息来增强 LLM 的响应。

## [OS9Map 让 Mac OS 9 连接现代社交网络](https://yllan.org/software/OS9Map/) ⭐️ 6.0/10

OS9Map 是一款新软件工具，能让 Mac OS 9 系统直接连接 Bluesky 和 Mastodon 等现代网络服务，无需中介代理服务器。 该项目通过将 20 年前的操作系统与当代去中心化社交网络连接起来，延长了老式 Mac 硬件的使用寿命，吸引了复古计算爱好者，并有助于保存数字历史。 OS9Map 在 Mac OS 9 上原生实现了对 AT 协议（Bluesky 使用）和 ActivityPub（Mastodon 使用）的支持，最低仅需 16 MB 内存，推荐 32 MB。

hackernews · LaSombra · Jun 25, 15:01 · [社区讨论](https://news.ycombinator.com/item?id=48674484)

**背景**: Mac OS 9 于 1999 年发布，缺乏对现代安全网络协议的内置支持，通常需要代理才能连接到今天的网络服务。AT 协议和 ActivityPub 是驱动去中心化社交网络的开放标准，允许不同服务器和客户端之间互操作。
