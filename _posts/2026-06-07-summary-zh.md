## [超越 fork() + exec() 模型](https://lwn.net/SubscriberLink/1076018/16f01bbbb8e0d1f0/) ⭐️ 8.0/10

LWN 的一篇文章和讨论认为传统的 fork()+exec() 进程创建模型已经过时，并提出了像 posix_spawn 和基于 clone 的机制等替代方案。 这很重要，因为 fork()+exec() 是 Unix 进程创建的基石；超越它可以在所有类 Unix 系统上提高性能、安全性和简洁性。 Fork 的时间复杂度为 O(N)（N 为进程内存大小）；即使有写时复制，它仍然代价高昂。像 posix_spawn 这样的替代方案避免了复制整个地址空间。

hackernews · jwilk · Jun 6, 14:34 · [社区讨论](https://news.ycombinator.com/item?id=48425528)

**背景**: 在 Unix 中，fork() 创建子进程作为父进程的完全副本，然后 exec() 加载新程序。这种设计对于 1970 年代的机器来说是高效的，但在现代系统中会导致开销和安全问题。写时复制优化了 fork，但并未消除根本性成本。

## [OpenAI 推出锁定模式阻止数据泄露](https://simonwillison.net/2026/Jun/5/openai-help-lockdown-mode/#atom-everything) ⭐️ 8.0/10

OpenAI 已推出锁定模式（Lockdown Mode），正在向符合条件的个人和自助服务企业账户推送，旨在限制出站网络请求，以减轻提示注入攻击导致的数据泄露风险。 该功能解决了 LLM 系统中的一个关键安全漏洞——'致命三重奏'（私人数据、不可信内容和泄露渠道）——通过切断最易限制的一条路径，使 ChatGPT 对高风险用户更加安全，而无需改变系统的其他部分。 锁定模式并不能阻止提示注入出现在处理过的内容中；它只阻止可能泄露数据的出站网络请求。OpenAI 首席信息安全官 Dane Stuckey 指出，该模式并非适用于所有人，但对于风险较高的用户来说，在功能和实用性上有所取舍，仍是有价值的工具。

rss · Simon Willison · Jun 5, 23:56

**背景**: 提示注入是一种网络安全攻击方式，通过恶意提示导致大语言模型（LLM）产生意外行为。数据泄露是指未经授权从系统中转移数据。'致命三重奏'描述了一种场景：LLM 系统同时拥有私人数据访问权、接触不可信内容的渠道以及窃取数据的方法。锁定模式旨在利用确定性机制打破数据泄露这一环节，这些机制不易受到基于 AI 的规避攻击。

vLLM 发布了 v0.22.1 版本，这是 v0.22.0 的补丁版本，包含来自 6 位贡献者的 8 次提交，新增了对 JetBrains Mellum v2 模型的支持、AMD Zen CPU 上的 zentorch 加速量化推理，并修复了 DeepSeek-V4 初始化、多节点 Ray 数据并行服务以及模型加载回归等问题。 此补丁提高了广泛使用的 LLM 服务基础设施 vLLM 的稳定性和性能，确保诸如 Mellum v2 等新模型的更顺畅部署，并在 AMD 硬件上提供了更好的 CPU 推理效率。 关键技术细节包括：修复了导致 DeepSeek-V4 初始化失败的 CUTLASS fmin 兼容性问题；在 AMD Zen CPU 上，将 zentorch 内核注册在通用 oneDNN 内核之前，用于 W8A8 和 W4A16 量化线性推理；修复了在 num_api_servers > 1 的多节点 Ray 数据并行服务中出现的确定性挂起问题。

## [Zeroserve：一个可用 eBPF 脚本化的零配置 Web 服务器](https://su3.io/posts/introducing-zeroserve) ⭐️ 6.0/10

开发者推出了 Zeroserve，一个零配置的 Web 服务器，它利用 eBPF 进行脚本化而非传统的声明式配置，定位为 nginx 和 Caddy 的替代品。 该项目展示了 eBPF 在用户态 Web 服务器中的新颖应用，可能带来更高的灵活性和性能，并通过减少对复杂配置语言的依赖来影响未来的服务器设计。 Zeroserve 用 Rust 编写，目前是单线程的；它接受用 C 语言编写的 eBPF 程序来定制请求处理，并计划通过 SO_REUSEPORT 添加多线程支持。

hackernews · losfair · Jun 6, 14:59 · [社区讨论](https://news.ycombinator.com/item?id=48425723)

**背景**: eBPF 是一种 Linux 内核技术，允许在内核空间安全执行沙盒程序，最初用于包过滤，现已扩展到可观测性、网络和安全领域。Zeroserve 将 eBPF 应用于用户态 Web 服务器逻辑，实现了无需修改内核即可自定义请求处理。
