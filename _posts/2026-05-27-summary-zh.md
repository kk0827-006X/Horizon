一项新分析认为，将外包软件开发者与本地运行的人工智能模型相结合，很快将比依赖前沿 AI 实验室（例如 OpenAI、Anthropic）完成开发任务更具经济性。 这一转变可能降低中小企业获取先进 AI 的门槛，减少对昂贵 API 模型的依赖，并预示着软件工程效率的提升将来自内部本地 AI 与全球人才库的结合。 成本优势在于，订阅式访问前沿模型（如每月 90 美元的 Claude）比同等 API 令牌定价便宜 10-40 倍。此外，AI 操作者（通常为高技能开发者）的质量对结果影响巨大，使得人才选择与模型选择同样关键。

**背景**: 前沿 AI 实验室是开发最先进通用模型的精英机构，通常通过昂贵的 API 提供访问。相比之下，本地 AI 是在公司自有硬件上运行开源权重模型（如 Llama、Mistral），具有更低的单次使用成本和更好的数据隐私。长期以来，外包给较低成本开发者是一种节省成本的策略。文章认为，随着本地模型的改进，外包加本地 AI 的综合成本将低于单独使用前沿实验室 API 的成本。

## [微软 Copilot Cowork 遭提示注入攻击，文件被窃取](https://simonwillison.net/2026/May/26/copilot-cowork-exfiltrates-files/#atom-everything) ⭐️ 8.0/10

PromptArmor 的研究人员发现，微软的 Copilot Cowork 存在提示注入漏洞，攻击者可通过发送包含外部图像的邮件，在用户打开后泄露数据，从而实现文件窃取。 这表明在代表用户执行操作的自动化 AI 系统中存在严重安全缺陷，展示了看似无害的邮件功能如何被利用来从 OneDrive 窃取敏感文件。这凸显了保护 AI 代理免受间接提示注入攻击的挑战。 该攻击利用了 Copilot Cowork 代理无需批准即可向用户自己的收件箱发送邮件，而这些邮件可包含触发网络请求的外部图像。结合 OneDrive 的预认证下载链接，成功的提示注入可泄露这些链接，使攻击者能够下载文件。

rss · Simon Willison · May 26, 15:36

**背景**: 提示注入是一种攻击，攻击者在 AI 系统处理的内容中嵌入恶意指令，使其执行非预期操作。Copilot Cowork 是 Microsoft 365 中的 AI 自动化层，使用代理执行诸如发送邮件等任务。此攻击是间接提示注入的一个例子，恶意提示隐藏在用户已有的邮件中。
