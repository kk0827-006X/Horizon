## [CSSQuake：仅用 CSS 和 HTML 渲染的《雷神之锤》](https://cssquake.com/) ⭐️ 8.0/10

CSSQuake 是《雷神之锤》（1996）的一个移植版，它通过 PolyCSS 引擎将 BSP 世界渲染成真正的 HTML/CSS 3D 几何体，完全不使用 WebGL 或 Canvas。它会预处理原始游戏数据为浏览器可用的 JSON 文件，并用 TypeScript 运行游戏逻辑，因此需要 JavaScript 才能运行。 这个项目展示了 CSS 3D 变换和基于 DOM 渲染的极致能力，将网页标准的边界推向了新的高度。它引发了关于浏览器性能、复古游戏和创意编程的讨论，激励了开发者社区。 CSSQuake 使用 PolyCSS 将《雷神之锤》的 BSP 地图转换为带有 3D 变换和 preserve-3d 的样式化 DOM 元素。它依赖 JavaScript 处理游戏逻辑、输入和资源加载，因此并非纯 CSS，但仍是重要的技术成就。

hackernews · msalsas · Jun 20, 10:49 · [社区讨论](https://news.ycombinator.com/item?id=48608223)

**背景**: CSS 3D 变换允许通过 transform-style: preserve-3d 和 perspective 在三维空间中定位元素。此前，诸如 cssDOOM 的项目已经证明可以用 CSS 重现经典游戏，而 CSSQuake 则将其扩展到了完整的 3D 引擎。PolyCSS 引擎预先计算几何体并将其转换为 CSS。
